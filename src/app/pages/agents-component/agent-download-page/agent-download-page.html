What is the CLM Agent?

The CLM Agent is a lightweight background service deployed on your infrastructure targets. It discovers local services, provision and certificates, and communicates these securely to the CLM Server. It also enforces automated renewal policies.

The CLM Agent is designed to run as a system service on your infrastructure targets.

Linux Installation

  1. Download the agent binary( agent-linux-vXXXX) and its SHA-256(agent-linux-vXXXX.sha256) checksum.
  2. Check the binary against its SHA256 checksum: sha256sum -c agent-linux-vXXX.sha256
  3. Run the agent as a system service.
